# 🥚 恭喜你发现了隐藏彩蛋！ / Congratulations on finding the Easter Egg!

如果你是一个喜欢翻看仓库目录的好奇宝宝，那么你赢了。

在构建 PCLA 的过程中，我深知自己并非从零开始。开源世界就像是一个巨大的赛博族谱，我们都在巨人的肩膀上摘苹果。你在这份源码里看到的，不仅是我的心血，更是一段跨越时间的代码传承：

### 🌍 万物的起点
- **Mojang 官方原生启动器**：它是这一切的起点。它定义了 Java 版 Minecraft 的启动规范与底层标准，是所有第三方启动器解构、学习与致敬的基石。

### 🧬 PC 端的开源明灯
- **HMCL (Hello Minecraft! Launcher)**：由 huanghongxun 及开源社区用爱发电的国内神作。它参考了官方原版的逻辑，并做出了极其强大的扩展。它的多版本管理架构，是无数后来者在黑暗中摸索时的指路明灯。

### 📱 安卓端的诸神黄昏与黎明
在这个手机运行 Java 版 MC 的硬核圈子里，有着极其悲壮且辉煌的生态：
- **PojavLauncher**：安卓端绝对的“基石与先驱”。无数启动器的渲染方案和底层代码（包括 FCL 和我）都源自这里。虽然原作者团队已停止维护，但社区接手后仍在延续它的生命。
- **Amethyst**：PojavLauncher 原作者指定的“正统继任者”，继承了其核心架构，是新生代的希望。
- **MojoLauncher / TurtleLauncher**：基于先驱者代码衍生出的高度定制分支，带来了更现代、更美观的 UI 体验。
- **FCL (Fold Craft Launcher)**：国内极其优秀的移动端先驱。它的底层逻辑流淌着 HMCL 的基因，而今天，PCLA 借用了它的原生库。
- **HMCL-PE**：HMCL 早期的移动端探索者，虽然现在官方更推荐其他方案，但它同样是不可或缺的尝试。

**技术的火炬就是这样传递下来的。**

从 Mojang 官方，到 PC 端的 HMCL，再到安卓端的 PojavLauncher 和 FCL，最后到今天，用手机硬搓出来的 PCLA。我们都在用代码，试图让这个方块世界在这个小小的屏幕上跑得更顺畅。

虽然我现在才 13 岁，只能用手机去“缝合”它们，但正如我在 README 里承诺的：**总有一天，我会把这些拼图完全融会贯通，用自己的代码写出属于 PCLA 的纯正底层！**

*If you are a curious soul who loves reading source code, you win.*

*During the development of PCLA, I know I didn't start from scratch. The open-source world is like a giant cyberpunk family tree, and we all stand on the shoulders of giants. What you see in this repository is not just my hard work, but a legacy of code passed down through time:*

*### 🌍 The Starting Point*
*- **Mojang's Official Launcher**: The absolute starting point. It defined the standards and specifications for launching Minecraft Java Edition, serving as the foundation for all third-party launchers.*

*### 🧬 The Beacon of PC Open Source*
*- **HMCL (Hello Minecraft! Launcher)**: A domestic masterpiece created by huanghongxun and the community. It referenced official logic and made massive extensions. Its architecture is a guiding light for countless successors.*

*### 📱 The Twilight and Dawn of Android Launchers*
*- **PojavLauncher**: The absolute cornerstone and pioneer on Android. The rendering solutions and native libraries of countless launchers (including FCL and mine) originated here. Although the original team stopped maintaining it, the community continues its life.*
*- **Amethyst**: The official successor designated by the PojavLauncher team, inheriting its core architecture.*
*- **MojoLauncher / TurtleLauncher**: Highly customized branches based on pioneer code, bringing modern UI experiences.*
*- **FCL (Fold Craft Launcher)**: An excellent mobile pioneer in China. Its logic carries HMCL's genes, and today, PCLA reused its native libraries.*
*- **HMCL-PE**: An early mobile explorer, an indispensable attempt.*

*This is how the torch of technology is passed down.*

*From Mojang, to HMCL on PC, to PojavLauncher and FCL on Android, and finally to PCLA built on a mobile phone. We are all using code to make this blocky world run smoother.*

*Although I am only 13 years old and can only "stitch" them together using a mobile phone right now, as I promised in the README: **One day, I will fully integrate these puzzle pieces and write the pure, native underlying code for PCLA with my own hands!***
